Autonomous Trading System

A project by Harry Winter · Python · Source code on GitHub

A Python pipeline that runs every weekday morning: it ingests market, macro and sentiment data, evolves trading strategies with a genetic algorithm, validates them out-of-sample, and executes on Alpaca paper trading behind hard circuit breakers.

The daily pipeline

  1. Data ingestion: equity and ETF prices (SPY, QQQ, sector ETFs, GLD, TLT, BTC) from yfinance, macro indicators from FRED (Fed Funds Rate, CPI, unemployment, 10Y Treasury, yield spread), Reddit sentiment and alternative data.
  2. Regime classification: labels the market as risk-on/risk-off and trending/mean-reverting, then adjusts signal weights and maximum position size.
  3. Strategy tournament: an evolutionary algorithm backtests strategy “genomes”, ranks them by risk-adjusted return and promotes a champion.
  4. Validation: the champion is tested walk-forward on out-of-sample windows before deployment. Overfitting is treated as an explicit design constraint.
  5. Execution: orders go through the Alpaca paper-trading API, with circuit breakers able to halt everything.
  6. Research loop: background agents fetch arXiv papers, scrape finance blogs and score sentiment, building a knowledge base that biases the next generation’s mutations.

Evolutionary strategy search

Each strategy is a genome encoding signal weightings, entry/exit conditions and position sizing. Underperformers are culled; survivors are mutated and crossed over. A researcher agent uses the knowledge base built from papers and market commentary to steer the mutation operator.

Risk management

  • Halt on a daily loss above 5% of equity
  • Halt on portfolio drawdown above 20%
  • Maximum position size of 10% of equity per ticker
  • Halt after 14 days at a 0% win rate
  • On a trigger, all positions are closed, a HALT file is written and a Telegram alert is sent

Self-analysis and red-teaming

A self-analysis agent reviews recent trades (including trades made in the wrong regime), and a red-team agent stress-tests the champion strategy against adversarial scenarios before it is trusted.

Architecture

  • data/: prices, macro, sentiment and alternative data
  • engine/: signals, regime classification, backtesting, portfolio and risk
  • strategies/: genome schema, evolutionary tournament and versioning
  • validation/: walk-forward out-of-sample testing
  • live/: position monitoring, circuit breakers and Alpaca execution
  • agents/: research, analysis and Telegram alerts
  • scheduler/: daily orchestration

Status

Paper trading only. This is a research and engineering project, not financial advice, and it is not intended to trade live capital without extended paper-trading validation.

Built with

Python, yfinance, FRED API, PRAW (Reddit), Alpaca API, Telegram, arXiv, pytest.
