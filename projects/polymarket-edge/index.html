polymarket-edge

A project by Harry Winter · Python · Source code on GitHub

A Python research toolkit with two parts: a scanner that looks for arbitrage in Polymarket’s multi-outcome markets, and a backtest of collecting funding payments on Hyperliquid. I’ve written up the results that didn’t work as well as the ones that did.

Polymarket negRisk scanner

In an event with N mutually exclusive outcomes, the YES prices should sum to 1.0. The scanner flags events where the sum deviates by more than a fee buffer, then walks each market’s full order book to check whether the gap survives at $50 and $500 per market.

Of 500 active events scanned, 19 were flagged at a 50bp buffer: 2 real, 5 marginal and 12 traps. By count, 63% were traps; by dollar volume, just 0.012%, because the 2026 FIFA World Cup event carried 95.9% of flagged volume. So whether it looks like a real opportunity depends entirely on how you count.

Hyperliquid funding-capture backtest

Across 12 major coins, 365 days and 105,120 hourly ticks, the strategy shorts the top-K coins by trailing funding and collects funding over the next interval. Gross out-of-sample return was +10.06% annualised, positive in 20 of 20 walk-forward windows, with a block-bootstrap 95% CI of +9.78% to +13.59%.

Trading costs kill it, though: at 5bp per leg, an 8-hour rebalance turns deeply negative. Only rebalancing every two weeks or less often stays positive after costs (+3.85% to +4.87% annualised).

Methods

  • Walk-forward validation (60-day train, 30-day test, 14-day step)
  • IID and stationary block bootstrap confidence intervals (IID is too narrow because funding returns are autocorrelated)
  • Tail-risk reporting: VaR, Expected Shortfall and drawdown
  • A market-maker simulator with three adverse-selection scenarios
  • A cross-venue lead-lag study (reported honestly as a null result after Bonferroni correction)

Engineering

  • Python managed with uv, about 92% test coverage with pytest
  • SQLite in WAL mode; GitHub Actions CI plus a nightly data job that snapshots to a data branch
  • Generated reports, matplotlib charts and single-file HTML dashboards

Built with

Python, uv, pytest, SQLite, matplotlib, GitHub Actions, Polymarket API, Hyperliquid API.
